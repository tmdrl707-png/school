# 학교 술래잡기

전주서중학교 교정과 5층 건물을 3D로 옮긴 브라우저 멀티플레이 게임이에요. 설치 없이 휴대폰·컴퓨터 브라우저에서 이름만 넣고 들어와요.

- **플레이:** https://tmdrl707-png.github.io/school/
- **규칙 안내(전자칠판용 슬라이드):** https://tmdrl707-png.github.io/school/guide.html
- `demo.html`은 예전 주소예요. 지금은 `index.html`로 바로 넘어가요.

## 게임 모드

선생님 화면(전자칠판)에서 방을 열고 학생들이 QR·방 번호로 들어오면, 선생님이 모드를 골라 시작해요.

- 자유놀기
- 🔴 술래잡기
- 🧟 좀비 게임
- 👮 경찰과 도둑

학생이 20명보다 적으면 봇이 함께 돌아다녀요.

## 조작

| | 컴퓨터 | 휴대폰(가로) |
|---|---|---|
| 이동 | W A S D | 왼쪽 화면 끌기 |
| 달리기 | Shift | 달리기 버튼 |
| 점프 · 기어오르기 | Space · 공중에서 한 번 더 | 점프 버튼 |
| 터치 · 엘리베이터 | E | 오른쪽 버튼 |
| 1·3인칭 | V | 설정 |
| 내 설정 | M (한 번 더 누르면 닫힘) | ☰ 버튼 |

아이폰은 Safari에서 **공유 → 홈 화면에 추가**로 넣으면 전체 화면으로 할 수 있어요.

## 만든 방식

- 한 장짜리 `index.html` (three.js, Firebase Realtime Database)
- GitHub Pages로 게시
- 경기 기록(`tag/logs`)은 선생님이 판 분석에 써요.
